# Minigame Mansion

A LAN party game for 2–8 friends: little blob characters, 30–60 second minigames, a scoreboard and a podium. Built with Godot 4.7 and Blender 5.2, with all code, models and sounds generated by AI agents directed in conversation.

## Play it

1. Download `minigame-mansion.exe` from the latest [Release](../../releases). No install: double-click it.
2. Windows SmartScreen may warn because the file is unsigned: **More info → Run anyway**.
3. When Windows Firewall asks, allow it on **both** Private and Public networks.
4. One friend clicks **Host game**; the others click **Join game** and pick the host from the list (or type the host's IP, shown in the host's lobby).

Everyone must be on the same network. Full guide: [docs/playtest.md](docs/playtest.md).

## Controls

| | Keyboard | Gamepad |
|---|---|---|
| Move | WASD / arrows | Left stick |
| Jump | Space | A |
| Shove | E / left mouse | X |
| Pause | Esc | Start |

## Minigames

Floor Is Lava, Bumper Sumo, Hot Potato, Coin Scramble, Cannon Alley, Paint Splat, Spotlight Chairs. More in [docs/expansion-ideas.md](docs/expansion-ideas.md).

## Building from source

Godot 4.7.2 and Blender 5.2 on Windows. Everything runs from the command line; see [CLAUDE.md](CLAUDE.md) for the tools (`tools\godot-check.ps1`, `tools\godot-test.ps1`, `tools\export-windows.ps1`) and [docs/contract.md](docs/contract.md) for how the systems fit together.
